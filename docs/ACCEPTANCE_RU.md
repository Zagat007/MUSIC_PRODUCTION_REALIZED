## Что исправлено при приёмке

1. Готовые программы были старше последних исправлений Клода. Обе сборки обновлены.
2. Сценарий сборки мог выбирать системный Python. Теперь он сначала ищет подготовленное окружение проекта,
   проверяет версию Python и наличие сборщика без обязательного обращения к сети.
3. Локальные HTTP-проверки зависели от сетевых настроек компьютера. Здесь запрос через настройки среды
   получал 503, а прямой запрос к тому же локальному серверу — 200. Проверочные клиенты используют прямое
   соединение (`trust_env=False`); сетевые настройки Windows не изменялись.
4. При пересборке в Codex сборщик подхватывал библиотеку ICU из набора инструментов Poppler. Она имела то же
   имя, но не содержала функций, ожидаемых QtCore. В результате приложение показывало ошибку загрузки DLL.
   Поиск зависимостей для процесса сборки теперь исключает папки `dependencies/native` инструментов.
   В повторной сборке посторонней ICU нет, QtCore загружается.
5. Проверка запуска считала любой живой процесс успехом, включая процесс с окном ошибки. Теперь она
   дополнительно проверяет журнал на исключения и ошибки загрузки.
6. Исправлен порядок импортов. Проверка Ruff проходит.
