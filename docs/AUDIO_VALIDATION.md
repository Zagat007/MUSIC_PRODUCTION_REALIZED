# Audio validation

What is verified by automated tests (synthetic, copyright-free fixtures generated by
`tests/audio_fixtures/make_fixtures.py`). Synthetic signals prove measurement/IO correctness only — **they do
not prove good musical mastering**. No acoustic recording with listening permission was available in this
environment: listening tests are **NOT VERIFIED** and must be done by the user.

| Area | Reference / method | Result |
|---|---|---|
| Integrated loudness | 1 kHz −23 dBFS stereo sine (EBU 3341) at 44.1/48/96 kHz | −23.0 ± 0.1 LUFS |
| LRA | 20 s @ −20 + 20 s @ −30 LUFS (EBU 3342 style) | 10.0 ± 0.2 LU |
| Cross-check | pyloudnorm (noise signal); FFmpeg `ebur128` on AAC/FLAC/WAV fixtures | ≤ 0.1 / ≤ 0.15 LU |
| True peak | analytic fs/4 tone at 45° (samples never at crest); FFmpeg `ebur128=peak=true` | 0.0006 dB / ≤ 0.3 dB |
| Limiter ceiling | +3 dBTP intersample tone, hard-clipped tones, +8 dB overdriven music, full-scale file start; −1 and −2 dBTP | output ≤ ceiling (re-measured) |
| Untouched regions | single spike in quiet music | samples ≥1 s away bit-identical |
| Zero latency | EQ + gain chain, cross-correlation | lag 0, same sample count |
| EQ accuracy | −1.5 dB bell at 3.5 kHz on noise | −1.2…−1.7 dB in band, < 0.1 dB at 80–300 Hz |
| Bit-exact conversion | ALAC 24-bit → WAV 24-bit | sample-for-sample identical |
| AAC/ALAC detection | ffprobe codec, not extension | AAC → lossy + warning; ALAC → lossless |
| Exported bytes | ffprobe + soundfile on WAV; checksums; FLAC vs WAV integer compare | PASS |
| MP3 preview | real libmp3lame 320k encode, decoded and measured | TP reported; overs flagged |
| A-B matching | preview clips re-measured | spread < 0.3 LU |
| Click repair | inserted 2-sample impulses | repaired, no new click, other channel untouched |
| Masked click | impulse on hi-hat burst | **not detected** (documented limitation) |
| Sources unchanged | SHA-256 before/after all operations incl. failures, 100-file batch | identical |

Evidence from a frozen-exe CLI run (`scripts/make_qa_evidence.py`) is in `tests/qa/evidence/`:
command log with exit codes, raw ffprobe JSON of every exported file, SHA-256 checksums, release validation,
album QA, manifest, unresolved warnings. Full test log: `tests/qa/pytest_log.txt`.
