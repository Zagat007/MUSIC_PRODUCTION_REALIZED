# Руководство пользователя (Suno Release Master)

Программа работает **локально и без интернета**. Аккаунты, оплата и облако не нужны. Исходные файлы
только читаются — никогда не изменяются, не перемещаются и не удаляются.

## 1. Установка
1. Установите бесплатный FFmpeg: `winget install Gyan.FFmpeg` (или укажите путь в `SRM_FFMPEG`/`SRM_FFPROBE`).
2. Запустите `dist\srm-gui\srm-gui.exe` (интерфейс) или `dist\srm\srm.exe` (командная строка).
   Сборка из исходников: `scripts\setup_windows.ps1`, затем `scripts\build_windows.ps1`.

## 2. Импорт альбомов
При запуске открывается простой интерфейс с тремя разделами:

1. **Моя музыка** — нажмите «Добавить музыку» и выберите папку. Если проект ещё не открыт, программа
   создаст отдельный проект в локальной папке приложения. Слева отображается дерево папки с альбомами:
   например, **НА РЕЛИЗ → 01 — AFTER THE LAST LIGHT**. Выберите альбом — справа появятся только его треки.
   Счётчики «В альбоме» и «Подготовлено», проверка и экспорт относятся к выбранному альбому.
   Последний выбранный альбом сохраняется при обновлении дерева в текущем сеансе.
2. **Прослушивание** — нажмите «Подготовить прослушивание». Программа создаст бережную обработку или
   загрузит уже подготовленную версию. Сравните «Оригинал» и «Обработка» кнопкой A/B; громкость выровнена.
   «Я прослушал — сохранить выбор» записывает ваше подтверждение только для этого трека и этой версии.
3. **Релиз** — выберите альбом. «Подготовить альбом» обрабатывает оставшиеся композиции, сохраняя уже
   подготовленные и одобренные версии. «Собрать черновик релиза» создаёт WAV, MP3 и отчёт проверки.
   Кнопка становится доступна, когда все композиции подготовлены. Проверка прав и данных об авторстве
   остаётся отдельным этапом; техническая проверка не означает одобрение звучания.

Точные измерения, ремонт дефектов и ручная цепочка находятся в разделе **Все инструменты**.
Для открытия существующей коллекции используйте «Открыть другой проект».

### Обложка и описание альбома

В карточке выбранного альбома есть описание и обложка. Если в папке есть `КОНЦЕПЦИЯ.txt`, описание берётся
оттуда при первом открытии. Изменения сохраняются в проекте автоматически; исходный текст не переписывается.

- **Загрузить обложку** — выбрать JPG/PNG/WebP. Создаётся отдельная квадратная копия RGB JPEG 3000×3000;
  прямоугольное изображение обрезается по центру. Исходная картинка сохраняется.
- **Создать абстрактный вариант** — бесплатная локальная графическая генерация: слова описания задают
  палитру и композицию. Это процедурный абстрактный дизайн, не нейросетевая иллюстрация. Каждое нажатие
  создаёт новый вариант; предыдущие сохраняются в списке под обложкой.
- **Вариант 1 / Вариант 2…** — выбрать предыдущую обложку. Выбор обновляет созданные MP3-превью альбома.

Обложка встраивается в ID3 каждого MP3-превью без повторного сжатия аудио. Она также попадает в следующие
пакеты релиза: `ARTWORK/cover.jpg` и все файлы `MP3_PREVIEW`. Готовые старые пакеты не изменяются; для новой
обложки соберите новый пакет. При проверке из каждого MP3 извлекается картинка и сверяется её контрольная
сумма. Качество дизайна и права на изображение подтверждаются человеком.

Расширенный сценарий импорта:

Меню **Проект → Открыть/создать проект**, затем **Добавить папку музыки и сканировать**. Подпапки становятся
кандидатами в альбомы. Найдутся M4A (AAC или ALAC — определяется по содержимому, а не по расширению), WAV, FLAC,
MP3 и текстовые файлы с промптами/текстами (`.txt`, `.md`, UTF‑8 или Windows‑1251).
* Совпадение текста: `MATCHED_EXACT`, `MATCHED_VARIANT`, `NEEDS_CONFIRMATION`, `AMBIGUOUS`. Подтвердите или
  отклоните: `srm text-match --track-id N [--text путь] [--reject]` — решение сохраняется при пересканировании.
* Дубликаты и альтернативные дубли отмечаются, но **никогда не удаляются**.
* Перенос трека в другой альбом и порядок: `srm album assign/reorder` (файлы не перемещаются).

## 3. Выбор источника
Лучше всего — WAV/FLAC/ALAC без потерь. Если есть только AAC (M4A), программа предупредит: WAV из AAC — это
**перекодирование, а не восстановление качества**; такой файл не подходит для Hi‑Res / Apple Digital Masters.

## 4. Анализ
Кнопка **Анализировать выбранные** (или `srm analyze`). Задание можно остановить и продолжить: готовые треки не
пересчитываются, ошибки по отдельным трекам не останавливают остальные. Вкладка **Анализ трека**: громкость
(LUFS, LRA), true peak, динамика, стерео/моно‑совместимость, спектр, темп (с вариантами половинного/двойного),
гипотеза стиля (низкая уверенность), кандидаты дефектов с временем, каналом, severity и confidence.
Отсутствие найденного дефекта **не доказывает**, что его нет. Металлические голоса и прочие ИИ‑артефакты
отмечаются как требующие прослушивания.

## 5. Режим обработки
* `ANALYZE_ONLY` — только отчёт.
* `CONVERT_ONLY` — WAV без изменения звука (для lossless — побитно точно, с проверкой).
* `SAFE_MASTER` — осторожная обработка: чаще всего лишь защита true peak и аккуратный уровень.
* `RESTORE_AND_MASTER` — только после утверждённого плана ремонта (вкладка **Ремонт**): щелчки исправляются
  интерполяцией, всё остальное — только с вашим одобрением; при неудачной проверке правка отклоняется.

Обязательного уровня −14 LUFS нет: стриминги сами выравнивают громкость. По умолчанию потолок −1.0 dBTP; для
очень громких мастеров — −2.0 dBTP.

## 6. Предложение, превью, одобрение
**Мастеринг → Предложить**: для каждого шага видно «проблема → доказательства → действие → риск → настройки».
Цепочку можно отредактировать (JSON с проверкой границ, любую стадию можно выключить). Затем **Рендер** и
**Создать превью A‑B**: исходник, версия и MP3‑превью **выровнены по громкости** — громче не значит лучше.
Слушайте, переключайтесь кнопкой A⇄B, щёлкайте по волне для перемотки. Затем **Одобрить версию** и
**Я прослушал(а) — подпись**. Версии неизменяемы: новые настройки = новая версия.

## 7. Экспорт и проверка
**Проверка релиза → Экспорт** (подтверждение обязательно). Пакет: `RELEASES\Альбом\v001\` с WAV, MP3‑превью,
FLAC (по желанию), QA‑отчётами, метаданными CSV/JSON, чек‑листами прав/ИИ и обложки, манифестом обработки и
файлом нерешённых вопросов. Проверка читает **реальные байты** файлов (кодек, битность, частота, каналы,
контрольные суммы, длительность, true peak, MP3‑перегрузки, FLAC = WAV).
Статус `DRAFT_NOT_RELEASE_READY` означает, что остались открытые вопросы (нет одобрения/прослушивания, не
заполнены права и раскрытие ИИ, источник lossy). Программа **никогда** не пишет «одобрено к релизу» и ничего не
публикует. Перед загрузкой проверьте актуальные требования вашего дистрибьютора (DistroKid и др.) и условия
Suno для дат создания/скачивания ваших треков. ISRC/UPC и авторов программа не придумывает.
